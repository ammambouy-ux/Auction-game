# Аукцион — online browser game

Браузерная multiplayer-игра на HTML/CSS/JavaScript + Node.js/WebSocket для 3–6 игроков. Создана отдельным проектом; не связана с репозиторием Tank-game.

## Текущие правила прототипа

- Комната содержит от 3 до 6 участников и приглашается по пятисимвольному коду.
- Создатель комнаты запускает матч; все участники должны нажать «Я готов».
- Матч состоит из 5 раундов, стартовый капитал — 5 000 монет.
- В каждом раунде всем показываются 3 общих лота. Каждый игрок выбирает один лот и подаёт закрытую ставку не ниже стартовой цены и не выше своего баланса.
- Ставки раскрываются после окончания раунда. Победитель лота — игрок с самой высокой ставкой. Каждый игрок может получить максимум один лот за раунд; если человек уже выиграл один лот, он не получает другие лоты в том же раунде.
- Купленные предметы нельзя продавать вручную. По завершении матча все предметы автоматически реализуются по их рыночной стоимости с учётом указанной особенности.
- Побеждает игрок с самой высокой чистой прибылью: сумма авто-продажи минус сумма затрат на приобретение предметов.
- У предметов нет редкостей. Особенность, если она есть, указывается прямо в карточке предмета. Улучшений предметов нет.

## Запуск локально

Нужен Node.js 20 или новее.

```bash
npm install
npm test
npm start
```

После запуска откройте `http://localhost:3000`. Для проверки настоящего онлайна нужны минимум три отдельных браузера/устройства.

## Размещение на Render

Создайте новый **Web Service** из GitHub-репозитория с параметрами:

- Runtime: `Node`
- Build command: `npm install`
- Start command: `npm start`
- Plan: `Free` (если доступен в аккаунте)

Сервер слушает `process.env.PORT`, отдаёт сайт и WebSocket endpoint `/ws` на одном домене.

## Ограничения прототипа

- Комнаты и состояние матча хранятся в памяти: при перезапуске сервера текущие матчи сбрасываются.
- Реализованы reconnect в пределах времени жизни комнаты, но нет постоянных аккаунтов или базы данных.
- Торги пока работают как закрытая ставка на один из трёх лотов: игрок выбирает один лот за раунд, а самая высокая ставка выигрывает. Время хода — до 45 секунд.
- Тонкая настройка баланса цен/бонусов будет идти после первых тестовых матчей.
